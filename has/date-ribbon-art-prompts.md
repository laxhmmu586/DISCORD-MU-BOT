# Reference-drawn date ribbon assets

Generated with the built-in imagegen tool, using the supplied Today and Short reference images. Real transparency is preserved; production assets are resized to 600 × 300 WebP. Text is rendered separately in HTML. Holiday shares the red artwork with a green color filter.

Outputs:
- `has/public/assets/schedule-ribbon-purple-3d-v1.webp`
- `has/public/assets/schedule-ribbon-red-3d-v1.webp`

## Purple prompt

Redraw the purple 3D Today ribbon in the supplied reference as a standalone transparent UI asset. Match the reference physical shape carefully: a wide horizontal satin-purple band with a gently convex front face, substantial rounded thickness, softly rounded right end, a left end that physically curls backward and downward to make a visibly hollow dark-purple rolled underside and short hanging curved tail. Bright lavender upper rim highlights, deep purple underside, polished dimensional studio render. It is a real sculpted ribbon wrapping over the upper-left corner of a calendar cell, not a flat rounded rectangle or a pill. Remove the calendar, all background, icon and text. The front face must be blank for live HTML text. Draw the ribbon level horizontally, no diagonal tilt; later the application will rotate it. Front face occupies x 12% to 90%, y 15% to 66%, with curled tail ending at y 90%. Single object fills canvas with only 5% transparent margin. Wide 2:1 canvas. Real alpha transparency, no backdrop, no fake checkerboard, no calendar icon, no writing.

## Red prompt

Redraw the red 3D Short ribbon in the supplied reference as a standalone transparent UI asset. Match the reference physical shape: a broad horizontal red satin band with a smoothly convex front face, substantial rounded thickness, rounded right end, and its left edge curling backward and downward into a hollow dark-red rolled underside and a short hanging curved tail. Soft coral-pink upper rim highlights and glossy bevel, rich red body, burgundy shadow under the band, polished dimensional studio render. It is a sculpted ribbon draped over a calendar corner, not a flat rounded rectangle or a pill. Remove calendar, background, tag icon and all text: the broad front face must be blank for live HTML text. Draw level horizontally with no diagonal tilt, application will rotate it. Front face occupies x12% to90%, y15% to66%; curled tail ends at y90%. One object fills frame with only 5% transparent margin. Wide 2:1 canvas. Real alpha transparency, no checkerboard, no icon, no writing.
