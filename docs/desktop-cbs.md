# Complete CBS in MUFC 2.1.2

The native global navigation previously replaced CBS's first navigation element, removing its eight section buttons. The full original sidebar is preserved: Open Case, Rush Bag, Add Baggage, Missing Bag Report, Email, Baggage Chart, Shipment and Closed Case, plus Form, Refresh, Logout and Settings. In MUFC 2.1.3, LBS has no additional top navigation row and no reserved space above the workspace. Other client pages retain their existing navigation.

The release packages current CBS page code and its complete dependency tree, including sidebar/category artwork, both baggage charts, dynamic baggage-identification pictures, PIR forms, the Three.js module chain, suitcase FBX and HDR environment. CBS and PIR forms are permitted as authenticated local pages. Existing handlers, dialogs, case editing, email attachments, marking damage and shipment actions are retained from repository sources. The loopback server forwards operations through its employee-authenticated, device-signed cloud proxy. Live events use the authenticated fetch stream adapter instead of an unsigned EventSource.

Jet Bridge is separately restored to the website at `/has-pbb.html` with employee authentication and original permissions. Website flight navigation, the footer shortcut and the small flight-card bridge icon point to it. Dashboard and CBS website URLs return the standard HTTP 404 Page Not Found. Report remains desktop-only.

Build with `scripts/prepare-desktop-navigation.cjs` using a protected client as the base and version `2.1.2`. `test/desktopCbs.browser.cjs` exercises the actual packaged server with simulated employee/business services: all eight sections, icon/chart loading, inline bag-tag editing, adding baggage, Rush creation, email with a PDF attachment, live refresh, CBS/PIR form navigation and successful 3D viewer initialization. Every cloud request is checked for a valid device signature and employee token. No real emails, records or shipments are created by tests.

The prior Report/navigation, login/sign-out, retired LakeTerm routes and employee-information protection checks also remain applicable. Windows installers are delivered for the user to run; the currently installed client is not replaced during verification.
