# Flight entries, operation modules, CBS corrections and account catalogue

Flight selection discovers entries from SY once and retains each detected flight for its Los Angeles operational date. Server snapshots survive restart; browser snapshots are scoped to the signed-in user and date. Later logs can update card metadata but cannot remove a detected same-day entry. The page has no periodic list/version requests. A server event notifies it only when card data changes. The existing shared BOX log loader feeds these updates; this feature adds no log-scanning timer. Manual Refresh remains available, and transient errors retain the current cards. Cards display only flight number/date in dark glass with a fine neon rim and a soft lower-right wave. The existing 3D Jet Bridge icon stays at the upper right. Desktop Dashboard/Boarding actions stack inside the frame; mobile shows only Boarding. The surrounding page and entry handlers are retained.

CREW APIS, GD CHECK, FSC, NEXTDAY INFO, NET, CCL, CC, INITIAL FLIGHT and BDT CHG keep independent completion records keyed by flight and date. Once completed, their saved evidence is reused across refreshes and service restarts. Completed log checks, GD/NEXTDAY email checks and the FSC lookup are skipped. Other live dashboard data continues to update. A later registration, crew or BDT change does not reopen a completed module. NEXTDAY INFO saves completion only after the existing delivery requirements succeed.

CBS passenger, wrong-baggage, On-hand/Bag Room and Rush Bag tag values support double-click editing (keyboard Enter also opens the editor). Enter or blur saves; Escape cancels. Invalid formats, duplicate active On-hand tags and stale edits are rejected. Background rendering pauses during editing. Corrections retain stable record IDs and case status; passenger snapshots and bag identification tags are updated together. Rush itinerary rows change atomically and retain a correction audit.

The September 2026 workbook supplies 200 unique station/account pairs in this order: West Coast, North Coast, Central, East Coast, South Coast, CBS. Exact workbook pairs override station-only geographic fallbacks. CBS worksheet pairs take precedence for duplicates. HAS-HQ is one HQ/HQ workspace. Source rows and normalized aliases are recorded in `profit-center-2026-sep-accounts.json`, without employee names or contact information.

Requested exclusions: CBS Call Center; HNL Ad Hoc Charter Svc; AUS KLM (WFS); JFK CHARTER; AUS CHARTER; DFW CHARTER. The one-time migration inserts missing accounts only, preserves existing accounts and personnel, and does not recreate subsequently deleted empty accounts. No workbook personnel are imported.
