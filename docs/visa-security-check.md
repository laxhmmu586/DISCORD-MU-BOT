# BN Security Check VISA rules

## SQLite + Rule Engine + AI 解释层

已在现有 Security Check 的 BN → VISA 接入规则引擎，使用 better-sqlite3 和 9 张表。默认本地库为 data/visa.db，服务器启动后运行官方政策监测；未部署线上。政策审核入口直接放在 BN 卡片内。

处理链：逐条 CKIN 归一化 → 提取证件／人工标记及其原文 → 合并护照和各行程段事实 → 按旅行日期匹配 SQLite 已审核规则 → 输出 PASS/REVIEW/FAIL、命中规则、依据和缺项 → AI 解释。

规则表保存国籍、目的国、护照类别、规则类别、结构化条件、生效／截止日期、复核时间、版本及审核状态。条件使用固定字段和固定操作符，不执行数据库中的代码。来源表保存官方机构、原页面、发布日期、抓取日期、正文快照和哈希；规则逐条关联具体条款。决策保存规则版本、原因代码、缺项、来源和单独的人工确认。

人工 240 是本地明确业务规则，优先于一般“需要签证”路径，无需用政府条件再次验证。BN 只审核国籍、目的地、普通护照类别、有效政策及 agent 记录的入境依据；不核查旅客的停留天数、旅行事由或累计停留历史，也不因这些字段未填而 REVIEW。政策限制仍完整保存，普通护照类别不明仍须复核；不能用没有 CKIN 证据直接判 FAIL。只有清楚的反证才 FAIL，存在其他可能适用路径时继续匹配。

可选 AI 解释接口仅收到结构化结论、缺项及来源，不发送原始 CKIN、姓名、护照号码或整份日志；不能改状态、补造日期、判断规则未涵盖的情况。BN 默认显示规则引擎解释，不依赖 AI。AI 未配置或不可用时保留模板解释。

政府网页变化先生成候选版本，经过审核后启用；生产规则不随抓取结果自动更改。政策已过期、超过复核期限、资料冲突或规则缺失时 REVIEW。已批准旧版本保留，便于按历史旅行日期重放决策。

- 外交部，2026-02-15 加拿大／英国免签公告：2026-02-17 至 2026-12-31。说明规则必须有政策期限，不能永久白名单。https://www.mfa.gov.cn/fyrbt_673021/dhdw_673027/202602/t20260215_11860462.shtml
- 国家移民管理局，2026-08-20 过境免签解释：当前公布 57 国、65 口岸及指定区域等条件。仅作为政策说明来源；本项目 CKIN 240 按用户确认视为人工核验完成。https://en.nia.gov.cn/n147418/n147463/c183412/content.html

## Security Check 实际接入范围

BN 的 VISA 项显示护照国籍、已托运目的地（沿用原解析逻辑）、签证要求、CKIN 检查记录、可能漏查标记及官方依据。API、TK、VISA、BAG 继续共同决定 BN 总体颜色，保留原有 Review Pass/Fail、CKIN OK 和 offload 行为。

- CKIN 240：人工核对完成，VISA PASS，不再次核对 TWOV 条件；NBRD 仍要求复核。
- 逐条识别 V/VS/VISA、重复 CKIN、EXP/TILL、空格月份日期；不跨备注借用日期或数字。中国目的地可沿用柜台未写 CHN 的 VISA 备注，其他目的地必须有相符签发国。
- 匹配目的地且有效期不早于旅行日的签证备注：表示 agent 已检查，VISA PASS。只写年份时，未来年份可表示已检查；当年或过去年份须核对完整有效期。
- 有效期和政策期限按目的地入境日期核对，不能用洛杉矶出发日代替中国入境日。LAX 赴中国大陆未明确入境日时，先按次日到后日的到达区间保守核对；跨越政策截止或证件到期时提示核实实际入境日。明确 CKIN ENTRY 日期才使用该日期，冲突或早于可能入境日的记录仍需复核。240 人工确认不因此重查。
- 有已审核“需要签证”规则但没有检查记录或其他入境依据：REVIEW / POSSIBLE MISSED CHECK。未实现规则不等同于需要签证，不据此指控漏查。
- PR CARD 识别为绿卡，但不自动当作中国签证；证件适用性、有效期不明或政策条件不全时 DOUBLE CHECK。

30 个国籍赴中国大陆的一般依据均已批准并保存 SQLite。俄罗斯当前问答来源为 https://cs.mfa.gov.cn/lh/lhqz_149493/cjwd/ 。中国领事服务网现行互免协定表为 https://cs.mfa.gov.cn/zggmcgx/cgqzapecswlxk/ylb/202607/t20260716_11984014.html 。

服务启动后按天查询官方栏目和既有政策页面，发现新链接或正文变化生成待复核记录；临近政策到期 30 天内改为每小时检查。免签规则在截止日之后、超过复核期限、来源变化、公告待复核或监测超过 72 小时未成功时不自动放行。监测失败不刷新成功时间。后台提醒目前写入本地记录及服务日志；未配置对外通知。

当前公告栏目监测覆盖中国入境政策。以后加入其他目的地的规则时，其官方政策页面也会持续检查正文变化，并受截止日期和人工复核期限约束；该国家的新公告栏目需要继续核实并配置，不能声称已经监测全球公告。

初始公告库存只将已经核实的 19 个精确快照一次性归档（visaPolicyInventory.json），包含已被当前政策取代的旧公告及需要另外核查的过境、区域政策。新公告、同一公告的新内容、无法核实的公告不会被这个初始化步骤清除。

运行 npm run visa:check 可手动更新来源。后台管理员令牌或者经服务器签名验证的 Firebase 审核账户可访问 /visa-api。默认审核账户沿用 lake@mu.com；VISA_RULE_REVIEWERS 可配置明确的审核账户名单，VISA_FIREBASE_PROJECT_ID 默认 china-eastern。不会相信客户端传入的审核人姓名，普通旅客 Review Pass/Fail 不会发布政策。

未覆盖组合自动进入 SQLite 待核实队列。BN 卡片内展开“复核此组合的政策并保存”，读取受支持的官方来源，核对签证要求／免签条件、政策生效和截止日期、复核日期、适用事由和累计停留限制，填写条款并确认。审核保存会原子创建并批准新版本，保存审核人和官方快照，同时清除对应待核实组合并刷新当前 BN 判断。更新失败不替换已批准规则。新规则按国籍、目的地和普通护照类别复用，不是当前旅客人工放行的复用。

授权复核后的规则优先于初始规则；规则到期、来源变化或超过复核期限后不会回退到旧免签政策。已知精确官方快照对应的截止日期和停留限制不能通过表单放宽；延期必须附新的官方依据。当前官方域名白名单见 visaSources.js。未列入白名单的新政府域名须先核实后纳入，不能使用个人博客或一般旅游网站。

规则和来源快照保存在 SQLite，BN 决策只记录输入摘要、状态、规则版本及人工标记，不保存旅客原始 CKIN。未覆盖队列只保存国籍、目的地、护照类别和检查次数／时间，不含旅客身份资料。该功能只判断 VISA 项，VISA PASS 不表示其他 Security Check 项也通过。

## CKIN 写法补齐（2026-10-12）

以柜台确认的语义识别 RESIDENT CARD（中国永久居留身份证）、PINK CARD（港澳居民来往内地通行证／回乡证）及 TRVL DCMNT／TRVL DOMENT（中国旅行证）。当前新增 USA → CHN 对应证件规则，其他国籍组合仍可通过 BN 政策审核保存。PR CARD 不写签发国时不猜为中国证件；明确 USA 等签发国时也不当作中国永久居留身份证。

统一识别 VISA／VS／V FREE 30 DAYS、V FREE 30DAYS、VISA FREE FOR 30DAYS、30DAYS V FREE，以及 DUAL／DURAL CITIZENSHIP ARM PPT。免签备注的天数用于核对其宣称的政策类别，不是旅客实际预计停留天数。双重国籍只有另一本护照国籍明确、有效期覆盖入境日时才能匹配该国籍规则；不会把 AMR 猜为 ARM，也不会把该护照号码当作签证号码。

有效期支持未来年份、06 JUL 2036、31 01 2027／31/01/2027 及 2028 12 20。DT 是可忽略的字段标记。日期仍严格校验，不能跨备注借用；签证号码末尾数字紧邻 EXP 不应被误当作月份日期。

新增 BRA → CHN 30 天政策（截止 2026-12-31）、ARM → CHN 90/180 天协议，以及 USA → THA 当前 30 天政策与 TDAC。BN 按要求不查事由、预计停留和累计停留历史，但数据库中的政策限制保持不变。TDAC 是独立入境卡，既不能替代签证，也不应被当作未记录检查；赴泰且未记录 TDAC 时仍复核。新公告栏目自动发现目前仍限中国，泰国两份官方政策正文会定期监测。

APEC CARD 单独识别为商务旅行卡并记录有效期。按柜台业务要求，赴中国内地的 CKIN 证件记录视为 agent 已完成适用性、中国准入及护照匹配核对，BN 不重复要求 CHN／PPT MATCHED 字段。有效期覆盖入境日时 VISA PASS；过期、有效期不明、明确相反签发国或 NBRD 仍须复核。

VISA PASS 只表示当前 BN 入境依据审核通过，不代表已核实政策规定的实际停留和旅行事由，也不改变其他 API／TK／BAG 检查。新增测试使用合成旅客和证件号码，保留用户提供的 CKIN 语法。

## Agent 已核验证件与月份错字补齐

赴中国内地时，APEC CARD、PR CARD／RESIDENT CARD、PINK CARD、TBZ、TRAVELDOC／TRVL DCMNT 的 CKIN 记录按 agent 已核对适用性处理。BN 不再显示 APEC 中国准入资格及护照匹配、居留或旅行证件适用性复核项，也不依赖按国籍发布的证件规则再次核对同一记录。决策会记录 CKIN_DOCUMENT_CHECKED、agent_confirmed 及证件类型；不会声称政府已自动核验卡片。仍保留有效期校验和明确签发国冲突检查，不跨备注借用签证日期。

SEPO 是已确认的 SEP 错字，29 SEPO 2035 解析为 2035-09-29；日历校验仍拒绝 31 SEPO、已经过期和多个冲突日期。CHN VS EXP DT 07 AUG 2036 表示中国签证，有效期 2036-08-07。

HUZ 加入中国内地机场识别。BN 的国内接驳判断合并现有完整内地机场表，避免 DYG 等机场因局部清单遗漏被当作未知目的国；保留 HKG、MAC、TWN 与中国内地的区分。中国护照经 PVG 前往 HUZ 按本国返回，无须签证。

补齐 TBZ CARD TILL 2030：即使主护照字段为 USA，赴中国内地仍按 agent 已核对的有效台胞证记录 VISA PASS，不再要求证明另一本台湾护照。补齐 V 30DAYS FREE／VS 30 DAYS FREE／VISA 30DAYS FREE；该语序与 V FREE 30DAYS 表示同一免签政策记录，仍核对政策国籍、宣称天数和截止日。

## 阿尔巴尼亚普通护照

新增 ALB → CHN 普通护照免签及 CKIN 90 DAYS VISA FREE 记录。中国驻阿尔巴尼亚使馆协定生效公告明确：2023-03-18 生效，每 180 天停留不超过 90 天。规则保存 90/180 条件和当前精确官方快照，没有把加拿大等临时免签的 2026-12-31 截止日期套到本协定。BN 不复核实际停留和事由，但仍要求普通护照类别、当前已审核来源和符合政策的备注；来源变化或过复核期时要求复核。该公告正文加入日常监测。
