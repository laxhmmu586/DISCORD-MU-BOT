HAS flight schedules are managed through Config to the left of Dashboard in the HAS Jet Bridge header. The Dashboard no longer contains a Config button. The existing lake@mu.com configuration restriction remains enforced on the server.

The dialog edits paired arrival/departure flight numbers, their independent Monday-Sunday operating days, station and account. It shows live weekly totals per leg and overall. Saving retains optimistic revision checks. Dashboard account rows show weekly arrivals and departures; Expected flights count Arrival and Departure separately on their respective operating days. The chart compares expected flights with submitted flights; bridge checklist totals remain separate because each flight can have multiple bridge forms. Flight coverage counts only submitted flights matching a configured leg and operating day. Open Dashboard tabs refresh on schedule notifications or focus, in addition to the existing 30-second polling.

Flight number includes both arrival and departure flights from the current employee station/account's saved schedule. Selecting a flight selects its operation; switching Arrival/Departure selects the corresponding flight from the same configured pair. Operation buttons are available before gate confirmation, while bridge selection still requires a confirmed gate for the selected flight. Existing legacy default-flight entries remain a fallback when that scope has no schedule. Add default flight and per-flight delete controls are removed from the checklist. Saving Config refreshes flight choices without restarting the page.

Approval Workflow is separately available as a full organization chart page from Admin. It uses the existing Uniform workflow API and preserves staged approval, revision conflicts and request snapshots.

Incomplete HAS checklists are deleted one hour after creation or the latest reset, regardless of answer activity. Cleanup runs at startup, every 30 seconds, and before authenticated API requests. Completed checklists and their PDFs are retained. Expiry updates shared bridge lists and returns open checklists to flight/gate selection. Gate locks keep their separate two-hour lifetime.
