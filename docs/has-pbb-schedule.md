HAS flight schedules are managed through Config to the left of Dashboard in the HAS Jet Bridge header. The Dashboard no longer contains a Config button. The existing lake@mu.com configuration restriction remains enforced on the server.

The dialog edits paired arrival/departure flight numbers, their independent Monday-Sunday operating days, station and account. It shows live weekly totals per leg and overall. Saving retains optimistic revision checks. Dashboard account rows show weekly arrivals and departures; existing Arrival expected-flight counts still count each pair once on its inbound operating days. Open Dashboard tabs refresh on schedule notifications or focus, in addition to the existing 30-second polling.

Flight number is an arrival-flight select populated from the current employee station/account's saved schedule. Existing legacy default-flight entries remain a fallback when that scope has no schedule. Add default flight and per-flight delete controls are removed from the checklist. Saving Config refreshes flight choices without restarting the page. Departure checklist behavior is unchanged.

Approval Workflow is separately available as a full organization chart page from Admin. It uses the existing Uniform workflow API and preserves staged approval, revision conflicts and request snapshots.
