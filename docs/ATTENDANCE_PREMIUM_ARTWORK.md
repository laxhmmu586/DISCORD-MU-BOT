# Premium request card scenes

Created with the built-in image generation tool using the existing employee illustrations as character references. Dynamic applicant data, labels, headings, the metallic rim, and right-aligned submitted time are rendered separately by `attendanceCards.js`.

Assets:
- `public/public/assets/attendance/late-luminous-v1.png`
- `public/public/assets/attendance/sick-luminous-v1.png`

The visible light trails belong to the scene. The card's outer edge is a thin metallic bevel with localized reflections, not a blurred neon ring. Both scenes are unbranded.

Headings use a bundled rounded Nunito Black face, layered shallow extrusion, silver/champagne gradients, and restrained highlights. The submitted timestamp is aligned to the bottom right. The scene contains no generated text; all real values are composited by the server renderer.
